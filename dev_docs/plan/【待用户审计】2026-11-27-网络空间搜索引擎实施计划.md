## 第一阶段 配置和批量连接测试

已完成本地实现和复审。真实供应商账户与套餐待验收。[实现复审](../review/【已复核】2026-11-27-网络空间搜索引擎配置复审.md)

1. **确认供应商契约。** 固定九个供应商标识，奇安信鹰图和 `hunter.how` 分别维护。核对凭据必填项、官方账户检查、HTTP 与业务状态码、限流和测试消耗，使用脱敏样例形成回包测试数据。资料未核实或没有目标无关检查的供应商允许保存配置并显示「未验证」，待有公开依据或经许可的账户验收后开放对应能力。
2. **建立独立的配置存储和权限边界。** 在服务端实现配置读取、保存、替换和清除。读取 DTO 只含引擎标识、配置和启用状态、修订及脱敏测试元数据。优先复用经核实的服务端密钥保管机制，保存时采用加密存储且加密密钥与数据分离。未核实可用方案前，使用模拟凭据验收，暂不开放生产凭据保存。审计只记操作、状态和时间，存储故障时返回错误并保留原配置。
3. **实现批量连接测试。** 仅由设置页显式触发，读取已保存的启用配置，以受控并发和超时请求固定的供应商 HTTPS 入口，禁用重定向并限制响应大小。将单家失败转换成独立结果。日志、错误和追踪均移除凭据、上游原始回包及敏感请求字段，对通过 URL 传递凭据的供应商额外覆盖 URL 脱敏。配置变更时用修订号阻止在途结果覆盖新状态。测试不自动重跑，重复点击复用正在执行的批次。
4. **实现设置页。** 在系统菜单「工具」下方加入「网络空间搜索引擎」，沿用现有侧栏、表格、状态和编辑面板组件。设计蓝紫色地球经纬线与放大镜图标，验证浅色、深色及收起状态的可辨识度。用紧凑列表呈现供应商、配置状态、最近测试结果，顶部「测试全部」展示批次进度和各引擎结论。保存后清空凭据输入，显式区分保留、替换和清除。测试中重复提交不产生额外请求，待保存修改提示先保存或放弃。
5. **完成第一阶段验收。** 用模拟 HTTP 回包验证凭据错误、套餐不足、限流、超时、上游错误、格式变化及部分成功。覆盖未登录、配置读写故障、同时轮换与测试、禁用后结果失效、重启后配置保留及已有安装升级。检查 GET、错误响应、页面状态、访问日志及任务导出均无凭据。真实账户验收按供应商记录凭据校验是否成功、是否消耗额度和不支持项。

## 第二阶段 人工被动核验和说明 Skill

6. **实现人工发起的资产核验入口。** 从现有授权资产详情发起，发送前显示资产类型、将外发的规范化标识和接收供应商。后端重查操作者权限、当前任务授权、资产与任务关系和拦截状态，验证单条公开域名、公开 IP 或已登记证书指纹。权限缺失、范围无法确认、套餐不支持或资产类型不受支持时拒绝或明确提示。覆盖边界与权限撤销的并发情形。
7. **展示第三方观察与核验状态。** 仅展示所选资产的必要字段、来源、查询与观测时间，并区分无记录、权限不足、暂不可用及上游部分成功。按最小权限渲染上游内容，限制结果体积和保留时间，禁止上游文本进入执行链。验证外部观察未写入任务范围、覆盖统计、漏洞发现或任务调度。域名、IP、证书各自按供应商能力验收；共享证书与共享 IP 只作为信息线索。
8. **编写结果解读 Skill 与操作文档。** Skill 仅解释操作者选定的结构化摘要，覆盖来源、缺失及时间差，不包含供应商查询语法、凭据或执行指令。实际功能验收后，在 `docs/` 增加用户操作说明，记录配置、轮换、测试状态、数据出站和支持范围。实现说明落到 `dev_docs/dev/`，上线前的评审结论和遗留项落到 `dev_docs/review/`。
9. **复审与发布验收。** 复查登录与任务授权、密钥泄露、供应商地址校验、上游内容注入、额度隔离、升级和回滚。运行 `git diff --check`、相关 Go 测试、前端仓库的 Biome 和 TypeScript 检查，以及配置页的交互验收。用合成结果验证普通任务、LLM、资产范围和交付报告的现有行为。按已批准的账户和许可完成上线前校验。遇到供应商或接入故障时通过禁用该来源回退，保留已收集的脱敏审计信息，停止新的外联。

## 完成口径

- 设置页按需求显示九家独立供应商，测试结果逐家可见。核验失败或缺少验证依据的供应商明确提示原因，不能显示为通过。
- 用权限和回归测试证明普通任务无需配置引擎即可运行，连接测试不触达任务资产，人工核验仅向用户选定的来源发送确认的公开资产标识。
- 复审确认上游错误、额度耗尽、密钥轮换与并发操作的行为，列出已测试的部署和账户套餐。确认未通过与未实测的项目均记录原因和发布状态。
