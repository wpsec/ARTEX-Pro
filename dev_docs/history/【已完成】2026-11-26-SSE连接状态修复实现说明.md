# 【已完成】SSE 连接状态修复实现说明

## 背景

开发构建通过浏览器所在主机名固定连接 `:8787`。当开发 UI 从其他本地端口打开时，SSE 可能进入另一 ARTEX 实例；同时 UI 在首次连接尚未建立时也显示“重连中”。

## 实现

- `web/src/lib/api.ts` 仅在标准 Next dev 端口 `3000`、`5173` 默认直连 Go 后端 `:8787`；其他端口使用同源 SSE。需要非标准 Next dev 端口直连时，使用 `NEXT_PUBLIC_SSE_BASE`。
- 会话页根据 EventSource 状态分别显示“连接中”“实时”“重连中”和“已断开”。浏览器自动重连、游标恢复及历史补偿逻辑保持不变。
- README 补充开发端口与 SSE 配置说明。
