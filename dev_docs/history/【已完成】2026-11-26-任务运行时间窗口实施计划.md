# 【已完成】任务运行时间窗口实施计划

本文记录 2026-11-26 双端时间窗口方案的历史评审。当前分支采用单一停止时间，使用方式见[任务停止时间](../../docs/2026-11-26-任务运行窗口.md)。

依据[已通过的需求评审](../review/【已通过】2026-11-26-任务运行时间窗口需求评审.md)，在任务时间窗口关闭时限制新增任务执行并暂停在途工作。时间窗开启需要人工确认才能开始或继续。

1. 定义单个每日窗口，校验时刻及 IANA 时区。计算跨午夜窗口是否开放及下一边界，保持任务超时独立。
2. 在任务创建事务内保存窗口及初始暂停状态。窗口配置使用服务端版本校验，留存修改前后值与操作时间。
3. 在现有运行入口增加窗口限制。进入窗口后仍需人工确认。关闭时撤销排队并取消受控在途工作。服务重启后，已配置窗口的任务重新等待人工确认。
4. 创建任务表单支持设置窗口，列表显示限制、下一边界和任务截止时间。主对话显示任务和修改前后的窗口，由用户明确确认保存。
5. 用受控时钟、合成任务和替身验证新增限制，覆盖截止、编辑、重启、排队与并发更新，并记录复审结论。
