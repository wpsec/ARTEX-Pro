# 【已完成】任务运行时间窗口复审

范围与 2026-11-26 确认的[需求评审](../review/【已通过】2026-11-26-任务运行时间窗口需求评审.md)一致。窗口关闭会让当前确认失效，自动暂停并撤销未开始的排队项。后续窗口开放时需要重新人工确认。配置更新与移除都会暂停任务，使之前基于旧时段的确认失效。修改接口复用应用现有鉴权，比较配置版本后才提交变更和审计。

| 验收项 | 结果 |
|---|---|
| 同日和跨午夜窗口、边界包含关系、IANA 时区、夏令时切换及非法输入 | Go 测试通过 |
| 配置持久化、并发修改冲突、修改与移除审计、匿名写入拒绝 | 隔离 PostgreSQL 17 测试通过 |
| 关闭时撤销排队和取消在途主对话、确认到期、重启丢弃旧确认、超时收尾的窗口拒绝 | Go 测试通过，覆盖合成运行状态及现有任务准入回归 |
| 创建表单、全局对话内的歧义选择和确认写入、任务详情内的窗口入口 | Chromium 模拟 API 回归 2 项通过 |
| 前端类型与新增组件、测试文件的 lint | TypeScript 与 Biome 通过 |

适用范围为任务 Planner、Worker、目标拆解、任务主对话和该任务的并发队列。独立对话中的复测及全局 Agent 触发器由各自流程控制。已发往外部服务的请求以该服务和审计所记录的结果为准。此次验收使用本地隔离数据库与模拟接口。
