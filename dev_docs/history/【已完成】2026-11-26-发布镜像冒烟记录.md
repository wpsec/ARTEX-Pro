## 2026-11-26 本地冒烟

使用本地 `artex-pro-dev:0.3.18`（镜像 ID `952311cb645d`，Linux ARM64，未标注源码 revision）。测试实例使用独立 PostgreSQL 17、独立数据卷及 Docker 内部网络，无宿主机端口发布。健康检查、嵌入登录页、认证初始化及空库验证通过。

- Judge 默认关闭，默认失败动作等于 `ask`，显式 `allow`、`deny`、`ask` 均可保存和读取。当前源码的本地模型替身测试通过 4 项，覆盖一次瞬时重试、连续瞬时失败的重试上限、确定性错误与关闭重试。
- 合成证据通过原文匹配，绑定用途调整后状态变回未核验。无 HTTP 证据的合成 finding 可读且保持未核验。
- 对话单删和批量删除均清理 transcript、附件和 Noa 文件。合成数据库错误触发后文件和对话记录均保留。
- 合成 MCP 计数总数为 3，两个工具分项分别为 2 和 1。任务发现过滤与详情返回已通过[本地 Chromium 回归](【已完成】2026-11-26-浏览器CI回归.md)，用例使用模拟 API。
