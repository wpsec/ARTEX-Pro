# 【已实现】任务运行时间窗口

任务保存可选的每日渗透测试暂停时间和配置版本。任务创建后立即执行，暂停时间一到即暂停渗透测试；支持 IANA 时区。PostgreSQL 与设置一并保存配置，配置变更与撤销排队在同一事务中提交。审计记录包含任务、版本、当前管理账户 `ARTEX`、修改前后配置和生效时间。[数据库实现](../../db/task_run_window.go) · [表结构](../../db/schema.sql)

到点会撤销未开始的排队项，并取消任务 Planner、Worker、目标拆解和任务主对话中受控的工作；已登记发现的 Reporter 会话不受影响，继续完成报告。编辑暂停时间或移除限制后，任务会自动重新准入，可沿用现有并发队列。任务超时仍使用既有的截止时间，超时发生在暂停期间时只进行必要的本地收尾。[服务端执行限制](../../server/task_run_window.go) · [准入与排队](../../server/goals.go)

创建表单、全局对话和任务主对话共享暂停时间字段。对话文字在前端生成配置草稿，由用户选择具体任务并确认，保存时直接调用带版本校验的设置接口；“停止时间”旧称仍可用于对话指令。[窗口组件](../../web/src/components/task-run-window.tsx) · [使用说明](../../docs/2026-11-26-任务运行窗口.md)
