# 【已实现】任务运行时间窗口

任务保存可选的每日停止时间和配置版本。到达配置的停止时间时暂停任务，支持 IANA 时区。PostgreSQL 与设置一并保存配置，配置变更与撤销排队在同一事务中提交。审计记录包含任务、版本、当前管理账户 `ARTEX`、修改前后配置和生效时间。[数据库实现](../../db/task_run_window.go) · [表结构](../../db/schema.sql)

到点会撤销未开始的排队项，并取消任务 Planner、Worker、目标拆解和任务主对话中受控的工作。任务超时仍使用既有的截止时间，超时发生在停止期间时只进行必要的本地收尾。[服务端执行限制](../../server/task_run_window.go) · [准入与排队](../../server/goals.go)

创建表单支持配置停止时间。任务列表和详情显示停止时间及状态，已经到期的任务会禁用继续按钮。[窗口组件](../../web/src/components/task-run-window.tsx) · [使用说明](../../docs/2026-11-26-任务运行窗口.md)
