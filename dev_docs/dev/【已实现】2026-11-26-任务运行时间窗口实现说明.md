# 【已实现】指定日期的任务定时启动与暂停

任务运行配置支持 `start_at`、`pause_at` 和 IANA `time_zone`。指定日期的自动启动与自动暂停各执行一次；等待启动的任务不进入 planner/worker，启动时经统一准入流程进入执行，暂停时间到达后转为暂停状态。配置以任务运行窗口 JSON 持久化，保留原有版本校验和审计记录。

进程重启后，尚未到启动时间的任务继续等待；启动时间已到且任务尚未启动时，经 bootstrap 准入流程启动；已启动任务恢复已有运行时。到暂停时间会撤销未开始的排队项，并取消 Planner、Worker、目标拆解和任务主对话中受控的工作。已登记发现的 Reporter 会话不受影响，继续完成报告。任务超时仍按首次开始后的既有截止时间计算，暂停期间也继续计时。[窗口服务端](../../server/task_run_window.go) · [任务准入](../../server/goals.go) · [窗口数据结构](../../db/task_run_window.go)

用户手动恢复已暂停任务时，过期的一次性运行安排会通过版本校验清除并写入审计记录，随后按正常准入流程继续；尚未到启动时间的任务只解除手动暂停，仍由定时守卫在计划时间启动。

创建表单和任务运行窗口对话框使用日期时间输入与时区字段。任务列表和详情显示待启动、运行中及已暂停状态；完整日期格式指令可生成待确认的表单草稿。新任务仅创建一次性计划；历史每日暂停配置仍能读取和编辑，不转换旧数据。[窗口组件](../../web/src/components/task-run-window.tsx) · [使用说明](../../docs/2026-11-26-任务运行窗口.md)
