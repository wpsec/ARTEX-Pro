# 【待验证】任务发现与 MCP 统计界面修复

## 功能范围说明

这里指任务详情中的“发现”列表与系统管理中的 MCP 调用统计展示，不是新的扫描能力或 MCP 连接配置页。变更内容包括发现详情返回时保留任务上下文、当前任务只显示自己的发现、关联任务选择器优先显示任务名，以及核对 MCP 分项计数与总数。截图中的 13 次调用由 `browser_navigate` 全部构成，计数一致，因此未改统计逻辑。

## 变更

- 将任务发现列表的“详情”改为更易点击的按钮，并在详情页保留任务上下文；返回时恢复原任务的“发现”页签。
- 任务详情的发现列表只展示当前任务自己的发现。关联任务仍可提供只读上下文，不再把其漏洞混入当前任务列表。
- 新建任务的关联任务选择器以任务名称为主标签；未命名任务回退到描述，描述和目标继续用于搜索。
- 核对 MCP 调用计数：截图中服务器总数为 13，`browser_navigate` 为 13，其余工具为 0，分项与总数相符，因此没有修改计数逻辑。
- 当时的手工构建曾使用应用版本 `2.2.1`；该版本号后来先被版本化构建的 `2.3.0` 取代，再由当前版本线修正。此处仅作历史记录。
