# 网络空间搜索引擎

打开系统菜单，在「工具」下方选择「网络空间搜索引擎」。页面列出 FOFA、奇安信鹰图、hunter.how、Shodan、ZoomEye、360 Quake、VirusTotal、ProjectDiscovery Chaos、SecurityTrails。奇安信鹰图和 hunter.how 各自使用独立的账户凭据。

## 配置和轮换

1. 选择供应商右侧的「配置」，从该供应商控制台或团队的安全存储取得对应凭据。
2. 保存后，列表显示「已配置」，再次打开编辑框时凭据为空。留空保留已保存值，填写新值则替换。替换、停用或清除凭据会使旧测试结果失效。
3. 暂停对某个来源发起连接测试时，关闭「启用连接测试」。需要删除该来源保存的凭据时，选择「清除凭据」并确认。FOFA 还可单独清除邮箱，保留已保存的 Key。

| 供应商 | 凭据 |
| --- | --- |
| FOFA | API Key。旧版需要注册邮箱时可填写该字段，当前版留空。 |
| 奇安信鹰图、hunter.how、Shodan、ZoomEye、ProjectDiscovery Chaos、SecurityTrails | API Key。 |
| 360 Quake | API Token。 |
| VirusTotal | API Key。用户 ID 可以选填，仅用于账户连接测试。 |

搜索引擎配置与 LLM 配置使用同一个 PostgreSQL 配置库。搜索引擎凭据单独加密。迁移或还原时，需要同时保留数据库和 ARTEX 数据目录中的 `cyberspace-search.key`，并限制该文件的访问权限。连接同一配置库的多个 ARTEX 实例须使用同一份搜索引擎加密密钥。

## 测试全部

「测试全部」使用已保存的配置，向对应供应商检查鉴权或账户信息。请求只包含供应商所需的凭据及账户标识，不携带任务域名、IP 或证书。

| 状态 | 含义 |
| --- | --- |
| 通过 | 供应商的账户或凭据检查成功。具体查询权益和额度取决于账户套餐。 |
| 失败 | 供应商拒绝检查、限流或不可达，或本地无法读取对应凭据。页面给出具体原因。 |
| 未验证 | 尚无独立验证方式，或未填写验证所需的账户字段。奇安信鹰图、hunter.how 和 Chaos 当前显示此状态。 |
| 已跳过 | 该供应商未配置凭据或已停用。 |

配置页的结果用于检查供应商连接。任务创建、资产范围和测试流程仍通过原有入口管理。
