# 渗透测试暂停时间

在**任务 → 新建任务**勾选**设置渗透测试暂停时间**，填写暂停时间和 IANA 时区。新建任务会立即开始自动化执行；每天到达设定时间后，系统自动暂停尚未结束的渗透测试。

渗透测试暂停时间只暂停任务的 planner/worker 执行，不会取消已登记漏洞对应的 Reporter 报告会话。已触发或排队中的报告撰写会继续运行，补全详细报告和交付报告；任务详情的报告页读取最新已保存内容。

可在全局对话、任务详情主对话或任务详情的**运行窗口**按钮中修改暂停时间。对话示例：`把任务 #42 的暂停时间改为晚上11点`，也可输入 `/window 42 23:00 Asia/Shanghai`。保存后配置立即生效，任务无需二次确认，会直接继续执行或加入并发队列。

任务列表和详情显示渗透测试暂停时间、当前状态及已有的任务截止时间。任务运行中时显示本次暂停的完整日期和时间；暂停时间已到时显示渗透测试已暂停。已完成、失败或超时的任务不显示下一次暂停时间。

暂停时间到达后，系统暂停渗透测试、取消受控的进行中工作，并阻止新的主 Agent 对话和意图重跑。修改暂停时间或移除该限制会重新准入任务；正在执行的超时终局判定会在配置变更时取消。任务级超时按首次开始后的实际经过时间计算，暂停期间也继续计时。

暂停时间到达后，可在任务详情的「报告」查看和复制截止交付报告。报告覆盖当前任务的已登记发现，已保存的分项报告可直接纳入，其余分项根据已登记的结论和证据状态整理。已触发或排队中的报告撰写会继续运行，报告撰写完成后刷新页面即可读取最新保存内容。
