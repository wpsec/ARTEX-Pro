# 定时启动与暂停任务

在**任务 → 新建任务**勾选**设置定时任务**，填写自动启动时间、自动暂停时间和 IANA 时区。任务按指定日期执行一次：到启动时间后自动开始渗透测试，到暂停时间后任务进入暂停状态。等待启动期间不会提前执行测试。

自动暂停只暂停任务的 planner/worker 执行，不会取消已登记漏洞对应的 Reporter 报告会话。已触发或排队中的报告撰写会继续运行，补全详细报告和交付报告；任务详情的报告页读取最新已保存内容。

可在任务详情的**运行窗口**按钮中修改定时安排。全局对话或任务主对话也可输入完整日期，例如：`把任务 #42 的自动暂停时间改为 2026-11-27 23:00`，由表单确认后保存。任务尚未启动时可调整启动与暂停时间；任务开始后只调整暂停时间。

任务列表和详情显示定时安排、等待启动/运行/暂停状态及已有的任务截止时间。启动和暂停时间均按所选 IANA 时区解释。已完成、失败或超时的任务不显示待执行的定时事件。

暂停时间到达后，系统暂停渗透测试、取消受控的进行中工作，并阻止新的主 Agent 对话和意图重跑。修改暂停时间会重新准入任务；正在执行的超时终局判定会在配置变更时取消。任务级超时按首次开始后的实际经过时间计算，暂停期间也继续计时。

暂停后可点击任务详情中的**恢复**继续执行。若一次性暂停时间已经到达，恢复时会解除已结束的定时安排；若任务仍在等待自动启动，恢复只解除手动暂停，任务仍会在计划启动时间开始。

暂停后，可在任务详情的「报告」查看和复制截止交付报告。报告覆盖当前任务的已登记发现，已保存的分项报告可直接纳入，其余分项根据已登记的结论和证据状态整理。已触发或排队中的报告撰写会继续运行，报告撰写完成后刷新页面即可读取最新保存内容。

先前创建的每日暂停配置仍可读取；新建的定时任务使用指定日期的一次性启动和暂停时间。
